# HorizonX

HorizonX is a full-stack space exploration platform that provides an interactive way to explore Earth imagery and Mars Rover photographs.

## Features

- Earth imagery gallery
- Interactive Earth image browsing
- Mars Rover photography
- Filter Mars images by rover
- Search Mars images by rover or camera
- Image preview modal
- User registration and login
- Responsive user interface
- Full-stack architecture with frontend, backend, and database

## Tech Stack

### Frontend
- React.js
- Vite
- Tailwind CSS
- React Router
- Framer Motion
- Axios

### Backend
- Node.js
- Express.js
- JWT Authentication
- Mongoose

### Database
- MongoDB Atlas

### Deployment
- Frontend: Vercel
- Backend: Render
